# 60–75 秒极简录屏脚本

不需要真人出镜，只录屏并配字幕；背景音乐使用网页内置音乐即可。

## 0–6 秒｜开场

- 画面：项目首页与标题。
- 字幕：`用 Binance 真实市场数据玩的交易卡牌游戏。`

## 6–18 秒｜选择战场

- 搜索一个交易对，例如 BTCUSDT 或 SOLUSDT。
- 在现货与永续合约之间切换，再展示做多、做空和杠杆选项。
- 字幕：`搜索 Binance 市场｜现货或合约｜全部为模拟交易。`

## 18–32 秒｜构筑交易人格

- 快速选择 4 张指标/策略/风险卡。
- 调整 MA、MACD 或 WR 参数。
- 字幕：`不同指标和参数，组成不同的交易人格。`

## 32–50 秒｜真实行情对局

- 点击开始，让 K 线播放。
- 做一次模拟开仓和一次平仓，展示明显的视觉与音效反馈。
- 字幕：`真实 Binance 历史 K 线盲测，与电脑同场竞技。`

## 50–62 秒｜结算与历史

- 展示收益、最大回撤、手续费、纪律评分和历史记录。
- 字幕：`不只看赚多少，也看回撤、费用和交易纪律。`

## 62–75 秒｜Agent OS

- 点击导出 Agent OS Coach Pack，短暂展示 JSON 与 Binance MCP 地址。
- 最后回到项目标题与 Demo/GitHub 地址。
- 字幕：`把对局交给连接 Binance MCP 的 AI，核验事实并生成学习复盘。`

## 录制注意

- 视频保持公开可访问。
- 不展示 Binance UID、余额、邮箱、2FA、密钥或 OAuth 信息。
- 不要说“保证盈利”或展示为真实下单。
