## 第 4 项｜项目文字说明

Alpha Coliseum Trading Lab 是一款使用 Binance 真实市场数据驱动的虚拟交易学习游戏，也是一套可交给 Binance Agent OS 复盘的交易训练工作流。玩家以 10,000 USDT 模拟资金进入未知的真实历史行情，选择现货或 U 本位永续合约模式，使用做多、做空、平仓、止损和 1–5 倍逐仓杠杆完成 3–8 分钟对局。玩家可以组合 MA、MACD、WR、成交量、策略与风险卡，调整周期和参数，形成自己的“交易人格”；电脑对手会在同一段行情中竞技。系统依据收益、最大回撤、手续费、过度交易与纪律执行进行结算，并保存本机历史战绩。项目读取 Binance Spot 与 USDⓈ-M Futures 公开市场、K 线、资金费率、持仓量和多空比数据；赛后可导出 Agent OS Coach Pack，交给连接官方 Binance MCP 的 AI Agent 核验市场事实并生成教育型复盘。所有交易均为本地模拟，不连接账户、不读取余额、不执行真实交易。

## 第 7 项｜分步骤指南

1. 打开公开 Demo，在市场搜索框选择 BTC、ETH、BNB、SOL 等 Binance USDT 交易对。
2. 选择“现货”或“永续合约”；合约模式可做多、做空，并选择 1–5 倍逐仓杠杆。
3. 从 MA、MACD、WR、成交量、趋势与风险管理卡中选择 4 张能力卡，调整指标周期和参数，生成自己的交易人格。
4. 点击“开始盲测挑战”。系统随机抽取一段真实 Binance 历史行情并隐藏日期，随后逐根播放 K 线。
5. 根据指标与风险规则操作模拟资金：现货可以买入、减仓和卖出；合约可以开多、开空、平仓。基础交易不依赖随机抽卡。
6. 对局结束后查看收益、最大回撤、手续费、交易次数、纪律评分、电脑对手表现和真实行情日期。
7. 在历史记录中回看最近对局；数据仅保存在当前设备，不需要注册账号。
8. 点击导出 Agent OS Coach Pack，把 JSON 发送给已连接官方 Binance MCP（`https://agent.binance.com/mcp/agentic`）的 AI Agent，请它核验当前市场状态并解释本局策略、风险和可改进参数。
9. 本项目只用于教育和娱乐；历史模拟不代表未来收益，不构成投资建议，也不会发起真实交易。
